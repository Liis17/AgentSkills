# AgentSkills

Набор навыков для Claude Code и Codex. Навыки устанавливаются в `~/.claude/skills` и `~/.codex/skills` навыком `updateskill`.

| Навык | Назначение |
|-------|------------|
| `obsidian` | Инициализация памяти проекта (Obsidian vault) и правил `AGENTS.md`/`CLAUDE.md` |
| `orchestration` | Оркестрация субагентов в T3 Code: роли, модели, ревью, повторы |
| `plan` | План задачи без написания кода, вопросы по дереву решений, ревью и подтверждение |
| `merge` | Доведение ветки до слияния: подтягивание родителя, проверки, PR, CI, merge |
| `updateskill` | Установка и обновление навыков из этого репозитория |

## Структура навыка

- Навык — папка верхнего уровня с `SKILL.md`. Имя папки совпадает с полем `name` во frontmatter.
- Подробности выносятся в `references/`, готовые файлы — в `assets/`. `SKILL.md` ссылается на них относительными путями.
- В каждой папке навыка есть `.version` — одно целое число без других символов.
- Текст навыков пишется на русском; имена файлов, маркеры и команды — как в коде.

## Версии навыков

- Любое изменение файлов навыка поднимает число в его `.version` на 1. В пределах одной ветки или PR версию поднимай один раз относительно `main`: перед коммитом сравни с `git show main:<навык>/.version`.
- Новый навык начинается с `.version` = `1`.
- При переименовании навыка переименуй папку и `name`, добавь строку `старое-имя -> новое-имя` в `skill-renames.txt` и подними версию.
- При удалении навыка добавь строку `имя ->` в `skill-renames.txt`.
- Строки в `skill-renames.txt` не удаляй: по ним `updateskill` убирает старые установки.
- При добавлении, переименовании или удалении навыка обнови таблицу навыков выше.

## Git

- Работа идёт в отдельных ветках и попадает в `main` через Pull Request.
- Сообщения коммитов и названия PR пишутся на русском и кратко описывают результат. Одна логическая группа изменений — один коммит.
- Перед коммитом проверяй `git diff --staged`: только изменения текущей задачи и поднятые `.version` изменённых навыков.
