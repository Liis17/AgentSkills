# Context7 — документация библиотек

Прочитай эту справку при опросе и при создании или обновлении блока `<!-- context7:start -->` … `<!-- context7:end -->` в корневом `AGENTS.md`. Context7 — MCP-сервер, который отдаёт актуальную документацию и примеры для конкретных версий библиотек и фреймворков.

## 1. Проверить, настроен ли Context7 (только чтение)

Context7 считается настроенным для агента, если выполнено одно из условий:

- в текущей сессии доступны инструменты сервера `context7`, например `resolve-library-id` и `get-library-docs` или `query-docs`. Если инструменты загружаются отложенно, проверь их поиском инструментов;
- сервер `context7` есть в конфигурации MCP:
  - Claude Code: `.mcp.json` в корне репозитория, `claude mcp list`, `~/.claude.json`;
  - Codex: `~/.codex/config.toml` или `.codex/config.toml` проекта, раздел `[mcp_servers.context7]`.

Запомни, для каких агентов и в каком scope (проект или пользователь) он найден. Ключи и токены из конфигурации не выводи.

## 2. Вопросы пользователю

1. **Использовать ли Context7:**
   - да (по умолчанию, если он настроен или в проекте есть внешние библиотеки и фреймворки);
   - нет — блок не создаётся. Если блок уже есть, он удаляется.
2. **В каких случаях** (несколько вариантов). Первыми предлагай варианты, подходящие стеку проекта:
   - API библиотек и фреймворков из manifests проекта — сигнатуры, параметры, поведение конкретной версии (по умолчанию);
   - настройка, конфигурация и интеграция библиотек и инструментов сборки (по умолчанию);
   - обновление версий и миграции между мажорными версиями (по умолчанию);
   - новая для проекта библиотека — перед первым использованием;
   - всегда перед написанием кода с внешней библиотекой.
3. **Настройка** — только если Context7 не настроен:
   - *настроить для проекта* — Claude Code через `.mcp.json` в репозитории, Codex через `.codex/config.toml` проекта, если версия Codex его поддерживает, иначе через пользовательский конфиг;
   - *настроить для пользователя* — во всех проектах (`claude mcp add --scope user`, `~/.codex/config.toml`);
   - *не настраивать сейчас* — блок создаётся с пометкой, что сервер не настроен.

   Уточни, для каких агентов настраивать: Claude Code, Codex или оба.

## 3. Настройка

Выполняй только по ответу пользователя. Это единственное исключение из правила «вне vault — только `AGENTS.md` и `CLAUDE.md`».

- **Claude Code:** `claude mcp add --scope <project|user> --transport http context7 https://mcp.context7.com/mcp`. Для `--scope project` команда создаёт или дополняет `.mcp.json`. Существующие серверы в нём сохраняй.
- **Codex:** добавь в конфиг раздел, если его нет:

  ```toml
  [mcp_servers.context7]
  command = "npx"
  args = ["-y", "@upstash/context7-mcp"]
  ```

- **API-ключ** необязателен: он нужен для повышенных лимитов. Если пользователь хочет его задать, запроси ключ через инструмент секретов, если он доступен. Ключ передавай через переменную окружения `CONTEXT7_API_KEY` или заголовок `CONTEXT7_API_KEY` в пользовательском конфиге. В файлы репозитория ключ не записывай.
- Если команда не сработала, сверься с актуальной инструкцией в README `upstash/context7` и сообщи пользователю, что именно не удалось.
- Новый MCP-сервер становится доступен после перезапуска сессии агента. Сообщи об этом в итоговом ответе.

## 4. Шаблон блока

Включи только выбранные случаи. Для каждого случая укажи реальные библиотеки проекта, если это помогает.

```markdown
<!-- context7:start -->
## Документация библиотек — Context7

Для актуальной документации внешних библиотек используй MCP-сервер Context7: сначала `resolve-library-id`, затем запрос документации с конкретной темой.

Используй Context7:
- {Случай 1, например: перед использованием API {Libraries} — сверяй сигнатуры и поведение для версии из manifests проекта};
- {Случай 2}.

- Версию библиотеки бери из manifests и lock-файлов проекта и запрашивай документацию для неё.
- Context7 не заменяет код проекта: устройство проекта смотри в памяти и исходниках, а Context7 — только для внешних библиотек.
- Если Context7 недоступен в сессии, сообщи об этом и используй официальную документацию библиотеки. Не опирайся молча на память модели.
<!-- context7:end -->
```

Если пользователь выбрал «не настраивать сейчас», добавь в блок строку: «Context7 в окружении не настроен: настрой его по README `upstash/context7` или повторным запуском `/obsidian`».

## 5. Повторный запуск

- Сверь блок с состоянием конфигурации. Если Context7 настроили или удалили, обнови пометку о настройке.
- Выбранные случаи и ручные уточнения сохраняй. Повторно спрашивай, только если блока нет или пользователь просит изменить правила.
