# /updateskill — обновить навыки из AgentSkills

Источник: `https://github.com/Liis17/AgentSkills`, ветка `main`. Другую ветку или ref используй, только если пользователь указал их явно.

Вызов навыка разрешает устанавливать, обновлять и удалять навыки этого репозитория в каталогах навыков агентов. Чужие навыки не трогай. Файлы текущего проекта не изменяй.

## Устройство репозитория

- **Навык** — папка верхнего уровня с `SKILL.md`. Имя папки совпадает с полем `name` во frontmatter.
- **`.version`** в папке навыка — целое число. Чем больше число, тем новее навык.
- **`skill-renames.txt`** в корне — переименования, по одной строке `старое-имя -> новое-имя`. Пустое новое имя после стрелки означает, что навык удалён.

## 1. Получить репозиторий

Скачай репозиторий во временную папку вне текущего проекта, например в scratchpad или в `mktemp -d`:

```sh
git clone --depth 1 --branch main https://github.com/Liis17/AgentSkills "$TMP/AgentSkills"
```

Если `git` недоступен, используй `gh repo clone Liis17/AgentSkills "$TMP/AgentSkills" -- --depth 1` или архив `https://codeload.github.com/Liis17/AgentSkills/tar.gz/refs/heads/main`. Запомни короткий SHA коммита для отчёта.

Составь список навыков репозитория: имя, версия из `.version` и путь. Пропусти папку и сообщи о ней в отчёте, если:

- у неё нет `SKILL.md` или `.version`;
- `.version` не является целым числом;
- имя папки не совпадает с `name` во frontmatter.

## 2. Найти каталоги установки

| Агент | Каталог |
|-------|---------|
| Claude Code | `~/.claude/skills` |
| Codex | `~/.codex/skills` |

Обновляй навыки во всех существующих каталогах из таблицы. Если ни одного каталога нет, спроси пользователя, для каких агентов установить навыки, и создай нужные каталоги.

## 3. Составить план для каждого каталога

Установленный навык считается **навыком этого репозитория**, если в его папке есть файл `.source` с URL репозитория. Этот файл навык создаёт при установке.

| Ситуация | Действие |
|----------|----------|
| Навыка из репозитория нет в каталоге | **Установить** |
| Установлена версия ниже версии в репозитории, или установленный навык без `.version` | **Обновить** |
| Версии равны | Пропустить. Если содержимое отличается от репозитория, отметь «локальные изменения» и не трогай |
| Установленная версия выше версии в репозитории | Пропустить и предупредить |
| Старое имя из `skill-renames.txt` установлено | **Удалить старое** — новое имя устанавливается или обновляется по правилам выше |
| Навык с `.source` этого репозитория, которого больше нет в репозитории и в `skill-renames.txt` | Спросить пользователя: удалить или оставить |

Учитывай особые случаи:

- **Навык без `.source` с тем же именем.** Он может быть старой ручной установкой из этого репозитория, а может быть чужим. Покажи начало его `SKILL.md` (frontmatter) и спроси пользователя, заменить или удалить его. После замены у навыка появится `.source`, и при следующих запусках вопрос не повторится.
- **Символическая ссылка.** Если папка навыка — символическая ссылка, например на рабочую копию репозитория, не заменяй и не удаляй её. Отметь в отчёте.
- **Разрешение на действия.** Установку и обновление выполняй без отдельного подтверждения: их разрешает сам вызов навыка. Удаление навыков, отмеченных `.source` или указанных в `skill-renames.txt`, тоже выполняй без подтверждения. Всё, что требует вопроса, собери в один раунд перед изменениями.

## 4. Применить

Для каждой установки или обновления:

1. Скопируй папку навыка из репозитория во временную папку рядом с целевой: `<каталог>/.<имя>.tmp`. Исключи `.git` и `.DS_Store`.
2. Запиши в неё `.source` — одну строку `https://github.com/Liis17/AgentSkills`.
3. Удали старую папку `<каталог>/<имя>`, если она есть, и переименуй временную в `<имя>`. Так навык не останется в наполовину скопированном состоянии.

Удаление — `rm -rf` только для конкретной папки `<каталог>/<имя>` после проверки, что путь находится внутри каталога навыков и не является символической ссылкой.

Временный клон репозитория удали в конце.

## 5. Отчёт

Покажи таблицу по каждому каталогу:

| Навык | Было | Стало | Действие |
|-------|------|-------|----------|

Действия: установлен, обновлён, удалён (переименован в …), пропущен (актуален, локальные изменения, версия новее, символическая ссылка, ошибка).

Укажи SHA коммита репозитория. Напомни, что новые и обновлённые навыки подключатся после перезапуска сессии агента.
